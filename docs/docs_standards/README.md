# Documentation Standards

## Overview

This directory holds the authoring standards that apply to everything written in this repository.
Read the standard that covers what you are editing before you edit it, and run `just docs-check` afterwards.

## Standards

- [Skill Authoring Standards](skill_authoring.md) - the frontmatter contract, naming, body structure, portability, and validation rules for a skill.
- [Agent Authoring Standards](agent_authoring.md) - the frontmatter contract, model and tool choices, body structure, and validation rules for a Claude Code agent.
- [Markdown Conventions](markdown_conventions.md) - the prose, structure, link, and lint conventions applied to every Markdown file.
